
# 🤝 Contributing Guide

Thank you for contributing to our **Team Portfolio Project** 🎉  

We’re excited to build this together. Please follow the steps below to keep everything organized.  

---

## 🚀 Getting Started  

1. **Fork the Repository**  
   - Click on the **Fork** button (top right of the repo).  

2. **Clone Your Fork**
  
   ```bash
   git clone https://github.com/your-username/team-portfolio.git
   cd team-portfolio 
   ```

3. **Create a New Branch**

Use your name for your branch:

```bash
git checkout -b add-portfolio-john
```

## 📝 Adding Your Portfolio

1. Go to the team/ folder.

2. Create a file named after you:
   -Example: person1.md → replace with your name.

3. Use this template:

```markdown
# 👤 Your Name  
## 🎯 About Me  
## 🛠 Skills  
## 📂 Projects  
## 📫 Contact  
## 📜 License  

```

4. Save and commit:

```bash  
git add team/yourname.md
git commit -m "Add portfolio for [Your Name]"
```

## 🔄 Updating README

- Edit the Team Portfolios table in README.md.

- Add your GitHub username and link your portfolio file.

Example:

```markdown
| 🟢 John Doe | [@johndoe](https://github.com/johndoe) | [View Portfolio](team/johndoe.md) |

```

## 📤 Submitting Changes

1. Push your branch:

```bash  
git push origin add-portfolio-john

```

2. **Open a Pull Request (PR)**

- Go to GitHub → Pull Requests → New PR
- Assign one teammate as reviewer
- Wait for approval before merging

---

## ✅ Code of Conduct

Be respectful.

Keep commit messages clear.

One PR per portfolio update
